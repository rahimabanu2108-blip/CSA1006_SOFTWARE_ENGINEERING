# BloodConnect – Blood Donor Management System

This repository contains the Software Engineering (Unit II) assessment project on **Requirements Engineering and Software Architecture**.

## Project Overview

BloodConnect is a conceptual Blood Donor Management System designed to help patients quickly find suitable blood donors during emergencies. The project focuses on software requirements analysis and UML-based system design rather than application development.

## Objectives

- Design a centralized blood donor management system.
- Identify functional and non-functional requirements.
- Model system interactions using UML diagrams.
- Demonstrate software architecture and requirements engineering concepts.

## Features

- Donor Registration
- User Login
- Search Blood Donors
- Blood Request Management
- Donor Verification by Administrator
